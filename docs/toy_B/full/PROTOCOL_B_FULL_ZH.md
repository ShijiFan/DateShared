## 1. 任务与划分（事先写定，防止选择过拟合）

- **搜索集 / 确认集**：每组按 itertools.permutations(years, 2) 的顺序给迁移编号 i。
  - i % 3 == 0 的进入搜索集，约 1/3；
  - 其余进入确认集。
  - 迭代过程**只看搜索集**。确认集只在搜索结束、候选冻结后运行一次。
- 说明：所有数据都已暴露。"确认集"只防止在搜索集上选择过拟合，不是盲测。真正的确认仍是新地区（主线 A 的 S5）。

## 2. 评估器（evalba.py）

- 一个候选 = (先验均值方程 m, 偏移基 B, 是否加残差 PPCA 模态)。全局参数（衰减 b、天气系数等）只在档案站点上拟合，用 toy_B 的 shift_table 或档案任务的 oracle 偏移。
- **系数尺度**：对档案每个任务，把 (oracle − m) 对 B 做最小二乘。
  - 系数方差按列类型取均值；
  - 残差方差按极化类型取均值；
  - 残差在键空间做 PPCA，秩按 80% 规则；
  - 与 p9_lib.phys_fit 做法相同，只是 m 换成候选均值。
- 先验 Ψ = B diag(s) Bᵀ + U Uᵀ + diag(e)，用 Woodbury 求逆；MAP-EM 用 gen_em2，λ = 0.1，与 P9 相同。
- **打分**：
  - 每个迁移的 BA；
  - 与 hpj_cov01、em_cov01、P9 的 hybridD_r* 做配对差，按测试方向（测 A、测 B）分别取中位数和为正的比例；
  - 选择分数 S = min(测 A 中位数, 测 B 中位数) of ΔBA vs hpj_cov01，即两个方向都要好。
- **复现检查**：评估器复现的 hpj_cov01、em_cov01、hybridD_r*、hybridD_r*_mw，在搜索集上必须与 P9 的 p9_basis_<grp>.csv 逐迁移一致（max|diff| < 1e-9）。不一致就停下排查，P9 尚未跑到的迁移等它跑完再核。
- **复杂度**：全局参数个数 + 基列数 K（按任务平均）+ PPCA 秩，用于 Pareto 前沿。

## 3. 迭代（LLM-SR 式）

- 每轮由我提 3–6 个候选，写明物理动机，评估后写反思，再提下一轮。共 ≤ 5 轮。
- 全部候选（代码名、参数、分数、反思）记入 full/B_FULL_LOG_ZH.md 和 results.jsonl。
- 候选方程的方向（预想，不限于此）：
  1. 均值方程：重新以档案平均为参照（m = m_arch + 天气异常项）；尺度在扣除天气均值后重新估计；
  2. 相干性天气项：两次获取之间的降水使相干性下降；
  3. 衰减对 VV、VH 分开；
  4. 基列结构：按日期共享但 VV/VH 分开，或按槽共享，等等。
- 不搜索 λ、NIT、80% 规则这些已固定的超参数。

## 4. 冻结与确认（事先写定）

- 搜索结束后，按搜索集选择分数 S 选出至多 2 个候选（若 S 相同，取复杂度低的），冻结代码和参数。在确认集上与 hpj_cov01、em_cov01、hybridD_r* 比较。
