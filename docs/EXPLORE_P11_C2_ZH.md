## 1. 做法

1. 每个迁移、每一折，用下列方法估计各类偏移 Δ_c：
   - **em**：em_cov01，即均值 EM 加 λ = 0.1，是最强的无先验基线；
   - **hpj**：hpj_cov01，全秩联合先验；
   - **lw**：hybridD_lw，冻结方法；
   - **oracle**：目标年标签给出的类均值差，作为上限；
   - **raw**：不平移。
2. 把源年 TRAIN 中 c 类样本平移 Δ_c，与 P4 相同（frozen.resynthesize）。然后重训分类器，预测目标年 TEST。
3. **分类器**：
   - HGB：冻结参数，与 JAG 线和 P4 相同（p3f_em.hgb，特征由 assemble 组装为 VV、VH、VH−VV、COH）；
   - RF：参数事先固定，n_estimators = 300，min_samples_leaf = 2，max_features = 'sqrt'，random_state = 20260923，同样使用 assemble 特征。
4. **迁移范围**：
   - HGB：三组全部 56 个迁移，五种 Δ 来源；
   - RF：todo[0::2]，取 raw、em、lw 三种；
   - 短档案 HGB：todo[0::2]，3 年子集只用 k3_0 和 k3_1（与 P8/P9/P10 相同），取 hpj 和 lw。

## 2. 判据（运行前写定；两个测试方向分别计算配对差）

| 编号 | 比较 | 通过条件 |
|---|---|---|
| C2a 主 | hgb_lw 对比 hgb_em | 两个方向中位数都 ≥ +0.01，且都至少 2/3 为正（同 P4 判据） |
| C2b | hgb_lw 对比 hgb_hpj | 两个方向中位数都 ≥ −0.003（不劣） |
| C2c 分类器无关 | rf_lw 对比 rf_em | 两个方向中位数都 ≥ +0.005，且都至少 60% 为正 |
| C3-HGB | 3 年档案（k3_0、k3_1 平均）：hgb_lw 对比 hgb_hpj | 两个方向中位数都 ≥ +0.003，且都至少 60% 为正 |

- 只报告：hgb_em 对比 hgb_raw；oracle 上限；"oracle 差距恢复比例"（由中位数计算）。
- 不通过的判据如实报告，不改方法。
