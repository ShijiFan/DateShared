# 法国 RPG → 7 类映射（2026-11-06 冻结；在查看任何地块数据之前写定）

- **依据**：IGN 官方编码表 REF_CULTURES_2024.csv（历史表，所列主代码自 2015 年起有效，CAMPAGNE_FIN 为空）和 REF_CULTURES_GROUPES_CULTURES_2024.csv。两份表都存在 newregion/fr_docs/，SHA256 见下。
- **字段**：code_cultu（parcelles_graphiques 图层）。
- **映射表**：FR_MAPPING_FROZEN.csv。所列代码在 2017–2024 各年使用同一张表。2023 年 CAP 改革后 PPH 的含义写作"6 年及以上的草地"，PTR 写作"5 年以下的临时草地"，二者仍然对应荷兰 BRP 的永久/临时草地二分。
- **明确排除**（不进入评估，统一记为 Other）：
  - MID（甜玉米）；
  - MCR（谷物混播，冬春不明）；
  - BDH、BDP（硬粒小麦）和 EPE（斯佩尔特小麦）：荷兰的类别定义里没有，量也很小；
  - SPH、SPL（带木本饲料的草场）；
  - MLG、MLC、CPL（以豆科为主的混播饲料）；
  - GRA（草坪或种子用草）；
  - 其他所有代码。
- **原则**：只保留能无歧义映射的代码；冬春不明的不纳入；不看计数结果改映射。
- **改动规则**：本表在地块计数之前冻结。以后如果发现某年使用了表外的同义代码（例如早年的青贮玉米、淀粉马铃薯代码），只能在用户签字后增补，并在本文件记录日期和理由。
