## 1. 记号

- 一个任务 = (组, 源年 ya, 目标年 yb, 折 k)。源年 TRAIN 拟合类均值 μ_c 和协方差 Σ_c，c 共 C = 7 类。
- 特征维按 dim_meta(S) 排列：VV(槽, 子) → VH(槽, 子) → COH(槽)。
  - 每个槽是一个 12 天像对。子 0、子 1 是像对的两次获取。
  - 维度的日期取源年 meta 中的 dates[2p + u]；COH 取像对中点；都换算成年积日 doy。
- 偏移 Δ = [Δ_1; …; Δ_C] ∈ R^{CD}，先验为 Δ ~ N(m, Ψ)。MAP-EM 使用 p5_cov.gen_em 的同一套更新，只改变 (m, Ψ)。

## 2. 偏移基

### 物理模态 B_phys（按任务计算，共 3 + C 列）

- **水平模态**，3 列：
  - L_VV：所有类的 VV 维为 1，其余为 0；
  - L_VH、L_COH 同理。
- **按类物候时移**，C 列：
  - T_c 在第 c 类的块内等于 ∂μ_c/∂t，其余为 0；
  - ∂μ_c/∂t 对 VV、VH、COH 分别按 doy 排序后用 np.gradient 求（单位：dB/天，或相干性/天）；
  - 系数 τ_c 的单位是天，正值表示目标年的曲线相当于源年提前或推迟 τ_c 天，即一阶泰勒近似。

### 物理模态的两种先验尺度

1. **phys_nom**（不用档案；名义尺度事先写定，之后不调）：
   - σ_L = 1.0 dB（VV、VH），0.05（COH）；
   - σ_τ = 10 天；
   - 残差独立，σ_0 = 0.5 dB（VV、VH 维），0.05（COH 维）；
   - m = 0。
2. **phys_arch**（尺度从档案估计）：
   - 对档案中每个任务，用它自己的源年 TRAIN 类均值算出 B_phys^(k)；
   - 把该任务的 oracle 偏移（p1_rows 的 target）减去 m，用最小二乘拟合得到 θ^(k) = (水平, τ_c)；
   - σ_L² 取各极化水平系数平方的均值；σ_τ² 取所有类 τ² 的均值；σ_0² 按类型取残差平方的均值；
   - m 取档案均值，与 hpj 相同。

### 学习模态 U（PPCA，学自档案；做法同 Jon et al. 2001）

- 档案向量取完整任务（build_joint 中的 V[full]），减去均值后做特征分解。
- 秩为 r 时：U = V_r (Λ_r − σ̄² I)^{1/2}。
- σ² 按类型（VV、VH、COH）取秩 r 重构残差平方在档案任务和该类型各维上的均值；σ̄² 是三类的加权平均，只用于 U 的缩放。
- Ψ_learn = U Uᵀ + diag(σ²_type)。
- 映射到任务维时，规则与 joint_for 相同：档案缺失的键，回退到同类型的平均方差。

### 混合（hybrid）

- 先对档案偏移做 phys_arch 的逐任务拟合，再对残差做 PPCA，得到 U_res。
- Ψ = B_phys diag(σ_a²) B_physᵀ + U_res U_resᵀ + diag(σ²_type)，m 取档案均值。

### 秩的规则（只用档案，事先写定）

- r* = 使档案方差（hybrid 用残差方差）的解释比例 ≥ 80% 的最小 r，按测试方向各算一次。
- 另报 r ∈ {2, 4, 8} 作为敏感性分析。

### 计算

- Ψ⁻¹ 用 Woodbury 恒等式计算。在第一个任务上与直接求逆比对，相对误差 < 1e-6 才继续。

## 7b. 追加变体：来自支线 B 玩具版（2026-11-05，P9 运行前加入；依据 toy_B/TOY_LOG_ZH.md）

**追加理由**：玩具版发现，主模态是"按获取日期、全作物共享、经 VH 植被衰减的偏移"。手写的"水平 + 时移"基只解释约 13–15% 的偏移。因此加入方程版的物理基。原有变体和 H1–H4 判据都不变。

**新变体**（全部 λ = 0.1）

| 名称 | 先验 | 说明 |
|---|---|---|
| physD_arch | B_disc = [日期列 × e^{−b(VH_src+25)/10}，按类时移]，b 固定为 1.0；系数尺度从档案估计（做法同 phys_arch） | 方程版物理基 |
| hybridD_r* | physD_arch + 残差 PPCA，秩规则同前 | **方程版主变体** |
| hybridD_r*_mw | hybridD_r*，先验均值换成水云天气方程 m(w)；参数 (a_p, b, k) 只在档案站点上拟合 | 检验天气先验均值 |

**额外判据**（同样按两个测试方向分别计算）

| 编号 | 比较 | 通过条件 |
|---|---|---|
| H1D | hybridD_r* 对比 hpj_cov01 | 等级定义同 H1（更好 / 不劣 / 更差） |
| H5 | hybridD_r*_mw 对比 hybridD_r* | 两个方向中位数都 ≥ +0.005，且都至少 60% 为正，即天气先验均值有用 |

**决策补充**
- H1 与 H1D 都是"更好"或"不劣"时，主方法选方程版 hybridD。理由是它有物理解释，并且玩具版中跨站点迁移更好。
- 这是按"可解释性"事先定下的偏好，不看 BA 谁更高再选。
- **多重比较**：本轮的候选变体变多了，"更好"的结论要等新地区确认。
